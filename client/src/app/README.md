# Campus Events

Campus Events is a small site where students can browse events at the university, sign up for them and, once logged in, organise their own. It is a full-stack web application built with an Angular frontend and a Node.js backend.

## Start Guide

To run this project locally, you will need to start both the backend server and the frontend client in separate terminals.

### 1. Backend Server
Open your first terminal, navigate to the server folder, and start the app:

> cd server
> node hello.js

*The server will be running at http://localhost:3000*

### 2. Frontend (Angular)
Open a second terminal, navigate to the client folder, and start the UI:

> cd client
> npm start

*The application will be running at http://localhost:4200*
